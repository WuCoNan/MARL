# 系统架构设计

## 1. 总体架构概览

本系统采用 **ns3 + Python 联合仿真** 架构，ns3 负责高保真网络事件驱动仿真，Python 负责强化学习模型训练与推理，两者通过共享内存（ns3-ai）或 Socket 通信实现协同。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          整体系统架构                                    │
│                                                                         │
│  ┌──────────────────────────┐         ┌──────────────────────────┐      │
│  │     ns3 仿真进程 (C++)    │         │   Python 训练进程        │      │
│  │                          │  共享内存  │   (PyTorch + PyG)       │      │
│  │  ┌────────────────────┐  │◄────────►│                          │      │
│  │  │  改进版 DSDV 模块   │  │  obs     │  ┌──────────────────┐   │      │
```

### 2.2 观测空间（Observation）详细定义

```
每个节点 i 的观测向量 obs_i:
┌──────────────────────────────────────────────────────┐
│  维度        │  含义              │  来源             │
├──────────────┼────────────────────┼──────────────────┤
│  queue_len   │  总队列积压(bit)    │  ns3 队列模块     │
│  buffer_use  │  缓冲区占用率(%)    │  ns3 节点状态     │
│  num_nbrs    │  活跃邻居数        │  DSDV 路由表      │
│  nbr_qual[]  │  到各邻居链路质量   │  ns3 链路模型     │
│  2hop_info[] │  2-hop 邻居状态    │  改进DSDV(工作点1)│
│  is_source   │  是否源节点(0/1)   │  流量配置         │
│  is_dest     │  是否目的节点(0/1) │  流量配置         │
│  traffic_load│  本地流量负载      │  ns3 流量统计     │
│  role_emb[]  │  角色嵌入(可选)    │  可学习参数       │
└──────────────────────────────────────────────────────┘

全局观测 = {obs_1, obs_2, ..., obs_N} + 拓扑图结构 G=(V,E)
```

### 2.3 动作空间（Action）详细定义

```
每个节点 i 的动作 action_i:

方案 A（离散动作）:
  action_i = next_hop_id  ∈ {neighbor_1, neighbor_2, ..., neighbor_k}
  含义：为当前包选择一个下一跳

方案 B（连续动作，推荐）:
  action_i = {fraction_1, fraction_2, ..., fraction_k}
  其中 fraction_j ∈ [0,1], Σ fraction_j = 1
  含义：将流量按比例分配到各邻居

  示例：节点 i 有 3 个邻居 A, B, C
  action_i = {A: 0.5, B: 0.3, C: 0.2}
  → 50% 流量走 A，30% 走 B，20% 走 C
```

### 2.4 奖励函数（Reward）设计

```
全局奖励:
  R_global = w₁·Throughput - w₂·AvgDelay - w₃·LossRate - w₄·Overhead

差分奖励（工作点3改进）:
  R_i = R_global - R_{-i}
  其中 R_{-i} = 假设节点 i 采取默认动作时的全局奖励

最终 per-agent 奖励:
  reward_i = R_i
```

## 3. 模型架构

### 3.1 GNN Actor + GNN Critic 对称架构

```
                    输入层                GNN 编码器              输出层
                    
                    ┌─────┐
 obs_i ────────────►│ 节点 │
 (节点特征)         │ 特征 │
                    │ 嵌入 │
                    └──┬──┘
                       │
                    ┌──▼──────────────────────────┐
                    │   GNN Layer 1 (GATConv)      │
                    │   h_i^(1) = GAT(h_i^(0),     │
                    │              {h_j^(0)})       │
                    │   attention 区分邻居重要性     │
                    └──┬──────────────────────────┘
                       │
                    ┌──▼──────────────────────────┐
                    │   GNN Layer 2 (GATConv)      │
                    │   h_i^(2) = GAT(h_i^(1),     │
                    │              {h_j^(1)})       │
                    │   感受野扩展到 2-hop          │
                    └──┬──────────────┬───────────┘
                       │              │
              ┌────────▼──────┐  ┌───▼──────────────────┐
              │  Actor Head   │  │   Critic Head         │
              │              │  │                        │
              │  MLP(h_i^(2))│  │   Readout({h_i^(2)})  │
              │      ↓       │  │   → GlobalAttention    │
              │  π(a_i|s)   │  │      ↓                 │
              │  每节点独立   │  │   V(s)                 │
              │  动作分布    │  │   全局价值估计          │
              └──────────────┘  └────────────────────────┘
              
  ┌─────────────────────────────────────────────────────────────┐
  │  共享策略（可选）:                                            │
  │  · 方案A: Actor/Critic 完全独立（推荐先用）                    │
  │  · 方案B: 共享 GNN Layer 1-2，各自独立 Head                  │
  │  · 方案C: Critic 比 Actor 多一层 GNN（更大感受野）            │
  └─────────────────────────────────────────────────────────────┘
```

### 4.2 Episode 结构

```
Episode 生命周期:

reset() ──────────────────────────────────────────────────► done
  │                                                          │
  ├─ 随机生成拓扑 (节点数、分布方式)                           │
  ├─ 建立 DSDV 路由表 (改进版，多路径)                        │
  ├─ 创建流量流 (源-目的对、速率、类型)                        │
  ├─ 初始化所有节点队列                                       │
  │                                                          │
  │   step 0 ──► step 1 ──► step 2 ──► ... ──► step T       │
  │     │          │          │                  │           │
  │     obs        obs        obs                obs         │
  │     ↓          ↓          ↓                  ↓           │
  │   action     action     action             action        │
  │     ↓          ↓          ↓                  ↓           │
  │   reward     reward     reward             reward        │
  │                                                          │
  └─ 结束条件:                                               │
     · 仿真时间到达 (如 5s = 500 steps)                       │
     · 所有流量传输完毕                                       │
     · 网络完全不可达                                         │
```

### 4.3 MAPPO 训练循环

```
┌─────────────────────────────────────────────────────────────┐
│                    MAPPO Training Loop                       │
│                                                              │
│  for episode in range(num_episodes):                        │
│      obs = env.reset()          # 随机化环境                 │
│      buffer.clear()                                          │
│                                                              │
│      for step in range(max_steps):                           │
│          ┌─────────────────────────────────────────────┐     │
│          │ 1. Actor 推理                                │     │
│          │    actions, log_probs = Actor(obs, graph)   │     │
│          ├─────────────────────────────────────────────┤     │
│          │ 2. Critic 估计                               │     │
│          │    values = Critic(obs, graph)               │     │
│          ├─────────────────────────────────────────────┤     │
│          │ 3. 环境交互                                   │     │
│          │    next_obs, reward, done = env.step(actions)│     │
│          ├─────────────────────────────────────────────┤     │
│          │ 4. 差分奖励计算（改进）                        │     │
│          │    reward_i = R - R_{-i}                     │     │
│          ├─────────────────────────────────────────────┤     │
│          │ 5. 存入 Buffer                               │     │
│          │    buffer.add(s, a, r, s', log_prob, value) │     │
│          └─────────────────────────────────────────────┘     │
│          obs = next_obs                                      │
│                                                              │
│      ┌─────────────────────────────────────────────────┐     │
│      │ 6. PPO 更新（每 K steps 或 episode 结束后）       │     │
│      │    for epoch in range(ppo_epochs):               │     │
│      │        # Actor 更新                              │     │
│      │        ratio = π_new / π_old                     │     │
│      │        advantage = GAE(r, V)                     │     │
│      │        L_actor = min(ratio·A, clip(ratio)·A)    │     │
│      │        # Critic 更新                             │     │
│      │        L_critic = MSE(V_pred, V_target)         │     │
│      │        # 总损失                                  │     │
│      │        L = L_actor + c1·L_critic - c2·entropy   │     │
│      │        L.backward() + optimizer.step()           │     │
│      └─────────────────────────────────────────────────┘     │
│                                                              │
│      # 记录日志                                               │
│      log(episode_reward, episode_loss, throughput, delay)    │
└─────────────────────────────────────────────────────────────┘
```

## 7. 关键技术选型

| 组件 | 选型 | 理由 |

```cpp
    // 收集所有节点的观测

    // 解析并应用 RL 的路由决策
    void ApplyActions(Buffer& action);
    
    // 计算全局奖励
    double ComputeReward();
    
    // 计算差分奖励（每个 agent 的边际贡献）
    std::vector<double> ComputeDifferenceRewards();
    
    // 获取拓扑图结构
    void GetTopologyGraph(Buffer& graph);
};
```
